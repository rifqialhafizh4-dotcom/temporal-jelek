Semua foto di sini datang langsung dari API, jadi album selalu mengikuti data terbaru tanpa perlu menyalin file satu per satu. Foto yang punya bingkai hitam di tepinya dipotong otomatis supaya tampil bersih dan penuh.

Cara kerja singkat
  1. Daftar foto dan kategorinya diambil dari API (temple.json) setiap halaman dibuka.
  2. Setiap foto dianalisis di browser: area hitam di tepinya dipotong otomatis, tanpa mengubah file aslinya.
  3. Tambah atau ubah foto cukup lewat data API — galeri dan beranda ikut berubah sendiri.
